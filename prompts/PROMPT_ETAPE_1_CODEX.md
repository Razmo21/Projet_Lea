# Prompt — Étape 1 du Projet Léa

Lis intégralement `AGENTS.md`, `README.md` et `TODO.md` avant toute modification.

Nous commençons uniquement l'étape 1.

Ta seule mission est de créer une petite interface locale avec React, TypeScript et Vite.

Elle doit contenir :
- un titre « Léa » ;
- une zone de texte permettant d'écrire une question ;
- un bouton « Envoyer » ;
- une zone de réponse.

Il n'existe encore aucun backend et aucun modèle d'IA.

Quand l'utilisateur clique sur « Envoyer », affiche simplement :

« Léa n'est pas encore connectée à son modèle. »

Je veux une interface simple et propre, sans identité visuelle avancée.

Avant de coder :
1. explique brièvement ce que tu vas créer ;
2. indique les fichiers et dépendances concernés.

Après avoir terminé :
1. lance les vérifications adaptées ;
2. confirme que `npm run dev` fonctionne ;
3. indique l'adresse localhost ;
4. liste les fichiers créés ou modifiés ;
5. signale toute erreur restante ;
6. arrête-toi.

N'ajoute rien d'autre :
- pas de backend ;
- pas de Python ;
- pas de modèle IA ;
- pas de mémoire ;
- pas de base de données ;
- pas d'accès aux fichiers ;
- pas d'Internet ;
- pas de Tauri ;
- pas de Docker.

N'entame pas l'étape 2.
