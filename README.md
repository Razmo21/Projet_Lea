# Projet Léa

Léa est une plateforme personnelle d'intelligence artificielle locale.

## Objectif actuel

Construire une toute première base minimale et stable.

Pour l'instant, l'objectif est uniquement de créer une petite page locale accessible dans le navigateur, avec :
- le titre « Léa » ;
- une zone de texte pour écrire une question ;
- un bouton « Envoyer » ;
- une zone d'affichage de réponse.

À cette étape, aucun modèle d'IA n'est encore utilisé.

## Philosophie

Une seule petite étape à la fois.

On ne commence jamais une nouvelle fonctionnalité tant que l'étape actuelle n'est pas stable, testée et validée.

## Technologies prévues

Frontend initial :
- React
- TypeScript
- Vite

Plus tard seulement :
- Python / FastAPI
- llama.cpp
- SQLite
- Qdrant
- Tauri

## Ordre de développement

1. Interface localhost minimale.
2. Backend minimal.
3. Connexion frontend/backend avec réponse fictive.
4. Installation et test du premier modèle local.
5. Connexion du modèle au backend.
6. Première vraie question et vraie réponse.

Tout le reste est reporté : mémoire, Développement, Santé animale, Vision, Web, RAG, voix, accès aux fichiers, automatisation.
